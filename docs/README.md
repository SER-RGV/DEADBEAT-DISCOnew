## Importante: por qué algunos informes siguen en la raíz

Hay informes antiguos que todavía están en la raíz del repositorio. Este índice los agrupa por tema sin moverlos todavía: antes de trasladarlos hay que comprobar y actualizar todos sus enlaces y referencias. Así evitamos dejar enlaces rotos o perder documentos.

Tampoco se eliminan archivos por tener el mismo contenido automáticamente. Algunas capturas o registros iguales pertenecen a pruebas distintas y deben conservarse como evidencia. Los dos HTML de entrada se mantienen porque el workflow de construcción los genera explícitamente.
