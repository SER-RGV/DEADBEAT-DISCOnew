# Tipografías del motion comic

Todas son tipografías libres (subconjunto latino, WOFF2) copiadas de los paquetes `@fontsource/*` v5.3.0 de npm.
Se guardan aquí para que la vista previa funcione sin conexión. Las licencias completas están en `licencias/`.

| Archivo | Familia | Uso en el cómic | Licencia |
|---|---|---|---|
| `comic-neue-latin-700-normal.woff2` | Comic Neue Bold | Bocadillos de diálogo | SIL OFL 1.1 |
| `comic-neue-latin-700-italic.woff2` | Comic Neue Bold Italic | Pensamiento, susurro y énfasis | SIL OFL 1.1 |
| `special-elite-latin-400-normal.woff2` | Special Elite | Cajas de narrador y línea secundaria de los rótulos | Apache 2.0 |
| `anton-latin-400-normal.woff2` | Anton | Rótulos de localización y tiempo, etiquetas de personaje | SIL OFL 1.1 |
| `creepster-latin-400-normal.woff2` | Creepster | Cartelas de transición y onomatopeyas de terror | SIL OFL 1.1 |
| `bangers-latin-400-normal.woff2` | Bangers | Gritos y onomatopeyas | SIL OFL 1.1 |
| `permanent-marker-latin-400-normal.woff2` | Permanent Marker | Onomatopeyas secas (pasos, mecanismos) | Apache 2.0 |
| `knewave-latin-400-normal.woff2` | Knewave | Rótulo de neón | SIL OFL 1.1 |
| `rubik-wet-paint-latin-400-normal.woff2` | Rubik Wet Paint | Onomatopeyas de impacto | SIL OFL 1.1 |

Para cambiar una tipografía: sustituye el archivo, actualiza `@font-face` en `comic.css` y el nombre en `data/guion.json → estilos`.
